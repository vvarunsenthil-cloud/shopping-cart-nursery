# Paradise Nursery Shopping App

Paradise Nursery is a simple online plant shopping application built as part of a final project.  
The application allows users to browse different plants, view basic details, and manage a shopping cart.

## What this project does
- Displays a list of plants with name, image, description, and price
- Allows users to add plants to a cart
- Lets users increase or decrease item quantities
- Calculates the total price based on selected items

This project was created to practice building a dynamic React application using components, state management, and basic styling.
